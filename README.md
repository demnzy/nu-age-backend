## Overview

The Nu Age backend is a RESTful API built with FastAPI, serving the core logic for course management, AI-powered content generation, real-time chat, gamification, and automated certificate delivery.

It is designed to be lightweight, low-latency, and resilient — built to serve students in environments where connectivity is unreliable and infrastructure tolerance is low.

---

## Architecture

```
Client (Flet Desktop / Mobile)
        │
        ▼
   FastAPI (REST API)
        │
        ├── Auth Layer (JWT)
        ├── Course Engine
        ├── AI Agent Integration (OpenAI / DSpy)
        ├── Chat & Community
        ├── Gamification Engine
        └── Certificate Generator
        │
        ▼
  PostgreSQL (via SQLAlchemy ORM)
        │
        ▼
  Alembic (schema migrations)
```

Hosted on an **AWS EC2** Linux instance behind an **Nginx** reverse proxy with SSL/TLS termination. Containerised with **Docker** for consistent local and production environments.

## Getting Started

### Prerequisites

- Python 3.11+
- PostgreSQL 15+
- Docker & Docker Compose (optional but recommended)
- An AWS EC2 instance (for production deployment)

### Environment Variables

Create a `.env` file in the project root. Never commit this file.

```env
# Application
APP_ENV=development
SECRET_KEY=your-secret-key-here
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=30

# Database
DATABASE_URL=postgresql://user:password@localhost:5432/nuage_db

# AI Integration
OPENAI_API_KEY=your-openai-key-here

# CORS
ALLOWED_ORIGINS=http://localhost:3000,https://yourdomain.com
```

A `.env.example` file is included in the repo with all required keys and no values.

### Running Locally

```bash
# 1. Clone the repo
git clone https://github.com/demnzy/nu-age-backend.git
cd nu-age-backend

# 2. Create and activate a virtual environment
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Set up your .env file
cp .env.example .env
# Fill in your values

# 5. Run database migrations
alembic upgrade head

# 6. Start the development server
uvicorn app.main:app --reload --port 8000
```

The API will be live at `http://localhost:8000`.
Interactive docs available at `http://localhost:8000/docs`.

### Running with Docker

```bash
# Build and start all services (API + PostgreSQL)
docker-compose up --build

# Run in detached mode
docker-compose up -d --build

# Tear down
docker-compose down
```

The `docker-compose.yml` spins up both the FastAPI application and a PostgreSQL container. Migrations run automatically on container start.

## Database

Nu Age uses **PostgreSQL** with **SQLAlchemy** as the ORM. The schema uses UUID-based primary keys throughout and is optimised for concurrent multi-cohort student enrollment.

### Migrations

Migrations are managed with **Alembic**.

```bash
# Apply all pending migrations
alembic upgrade head

# Roll back one migration
alembic downgrade -1

# Generate a new migration after model changes
alembic revision --autogenerate -m "describe your change here"

# Check current migration state
alembic current

# View migration history
alembic history
```

> Always review autogenerated migration files before applying them. Alembic does not always detect relationship changes perfectly.

## Authentication

Nu Age uses **JWT (JSON Web Tokens)** for stateless authentication.

| Flow | Detail |
|---|---|
| Login | `POST /auth/login` returns an `access_token` and `refresh_token` |
| Protected routes | Pass `Authorization: Bearer <token>` in the request header |
| Token expiry | Access tokens expire in 30 minutes by default (configurable) |
| Refresh | `POST /auth/refresh` with a valid refresh token returns a new access token |

Passwords are hashed using **bcrypt** before storage. Raw passwords are never persisted.

## API Reference

Full interactive documentation is available at `/docs` (Swagger UI) and `/redoc` when the server is running.

### Core Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/auth/register` | Register a new user |
| `POST` | `/auth/login` | Obtain access and refresh tokens |
| `POST` | `/auth/refresh` | Refresh an expired access token |
| `GET` | `/users/me` | Get current authenticated user |
| `GET` | `/courses` | List all available courses |
| `POST` | `/courses` | Create a new course (tutor/admin) |
| `GET` | `/courses/{id}` | Get course details and modules |
| `POST` | `/courses/{id}/enroll` | Enroll in a course |
| `GET` | `/courses/{id}/leaderboard` | Get live course leaderboard |
| `POST` | `/ai/generate` | Generate lessons/quizzes from syllabus |
| `GET` | `/chat/{course_id}/messages` | Fetch course channel messages |
| `POST` | `/chat/{course_id}/messages` | Send a message to a course channel |
| `GET` | `/certificates/{user_id}` | List user certificates |
| `POST` | `/certificates/generate` | Generate certificate on completion |

## Deployment

Nu Age's backend is deployed on an **AWS EC2** Linux instance.

### Production Setup Summary

```bash
# 1. SSH into your EC2 instance
ssh -i your-key.pem ubuntu@your-ec2-ip

# 2. Clone the repo and set up environment
git clone https://github.com/demnzy/nu-age-backend.git
cd nu-age-backend
cp .env.example .env
# Fill in production values

# 3. Build and start with Docker
docker-compose -f docker-compose.prod.yml up -d --build

# 4. Run migrations
docker-compose exec api alembic upgrade head
```

**Nginx** is configured as a reverse proxy in front of the FastAPI container, handling SSL termination via Let's Encrypt. Ensure ports 80 and 443 are open in your EC2 Security Group, and port 8000 is restricted to internal access only.
